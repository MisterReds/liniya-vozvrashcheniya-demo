## Статус

Это предпроизводственная версия 0.1. Документ 13 предлагает собственный C++/SDL3 движок и Windows PC первым таргетом. Текущий HTML демо — только браузерная проверка идеи, не основа финальной PC-сборки.

## Запуск демо

Текущий браузерный прототип доступен на [GitHub Pages](https://misterreds.github.io/liniya-vozvrashcheniya-demo/). На ПК используйте A/D, E и пробел; на узком экране есть кнопки под сценой. Карточки жителей меняют их назначение. Прототип не является production-сборкой.

## Собственный PC runtime

Собственный C++20/SDL3 движок собран в playable vertical slice; описание и сборка — в [engine README](engine/README.md). WebAssembly-сборка открывается на той же GitHub Pages ссылке; браузерный shell даёт touch-кнопки, симуляция и пиксельный рендерер работают из C++.

## Рабочая формула

**2D стратегия с прямым управлением героем, исследованием, набором выживших и обороной поселения.** Игрок начинает у Чернобыльской зоны, восстанавливает транспортный и энергетический коридор, а затем продвигается к Москве и другим регионам. Главная цель — не пережить конец света, а вернуть людям связанную инфраструктуру и возможность строить будущее.
